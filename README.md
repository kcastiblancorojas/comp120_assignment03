# Tasks feature in the Project

This project allows users to add new tasks to a to do list  
The “Add a Task” feature was implemented as part of the project workflow using issues, branches, commits, and pull requests.

## Features
- Add a new task
- Display all tasks in a list

## How to Use

### 1. Open the Application
Open the project in your browser 

### 2. Add a Task
1. Type the task (what needs to be done)in the input box 
2. Click **Add Task** 
3. The new task will appear immediately in the task list.

### Sample 
1. Type: 'Buy milk'
2. Click the **Add** button
3. The task now appears in the to do list:
   - Buy milk
